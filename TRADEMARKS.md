# RIW: uso de la marca e identidad visual

RHYNUS Interactive Works (RIW) distingue este proyecto de sus derivados. El nombre «RHYNUS Interactive Works», sus emblemas y logotipos son elementos de identidad institucional.

La licencia GNU GPL v3 aplicable al **código fuente** no constituye una licencia de marca ni autoriza afirmar que un proyecto derivado está patrocinado, aprobado o mantenido por RIW.

El logotipo `assets/branding/RIW_Logo_Principal_Horizontal_Transparente_v1.png` se incluye para representar la aplicación original. No se ofrece como un recurso gráfico genérico bajo CC BY-SA. Si deseas utilizarlo para identificar productos, servicios o proyectos independientes, solicita permiso al titular.

Puedes citar de forma descriptiva la procedencia del proyecto y conservar los avisos de autoría/licencia exigidos por GPL. Para un fork, identifica claramente los cambios y evita sugerir una afiliación oficial inexistente.

Este archivo no reduce ni sustituye los derechos que otorga la GPL sobre el software. Si surgiera un conflicto respecto a derechos de autor de recursos gráficos, deben revisarse las condiciones de esos materiales separadamente.
